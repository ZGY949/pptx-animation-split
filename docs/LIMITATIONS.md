# 支持范围与已知限制

## 拆分方式

按 `presentation.xml` 中的放映顺序读取源页。每张源页先输出初始状态，再为主动画序列中每个识别到的点击组输出终态；同组的“与上一动画同时”“上一动画之后”合并在一起。没有动画的源页输出一页。

未识别的动画结构、对象触发的交互动画及非标准文件可能不能按预期拆分。日志只报告解析器检测到的未支持效果，不代表能识别文件中的所有不支持情况。

## 具体支持条件

| 类型 | 当前处理方式或条件 |
| --- | --- |
| 进入、退出 | 按点击顺序重放对象和段落显隐，支持对象再次进入 |
| 段落 | 用透明占位保留文字、字体、换行与位置，不删除段落 |
| 公式 | 同步处理 Choice/Fallback 兼容分支，保留原生结构及所需命名空间；按显隐筛选旧式 OLE/VML 预览 |
| 文字变色 | 识别到 `style.color` 且有明确目标颜色的部分效果 |
| 旋转 | 有明确 `by` 角度的旋转终态 |
| 图片缩放 | 正数 `by` 比例，以中心为基准，保留裁剪 |
| 分组缩放 | 保留内部坐标；含文字时仅支持等比缩放且文字有显式字号，同时调整字号和间距 |
| 直线移动 | 顶层对象、`origin=layout`、未旋转的单段 `M … L …` 路径；同一对象仅一次路径移动 |
| 瞬时强调 | 已识别为 `fill=remove` 或自动反向、结束时复原的效果保留原状态 |

不支持文字框直接缩放、复杂或曲线路径、分组内部路径、同一对象多次路径及其他未实现的强调效果。视频或音频播放过程不能转成静态动画步骤；媒体文件可能仍保留在输出包中。

移除幻灯片动画不会冻结媒体内容。GIF 图片在演示软件中仍可能自行播放，本工具不会将 GIF 或视频逐帧展开或自动转成静态图片。

## 文件和显示限制

- 仅接收 `.pptx`。旧版 `.ppt`、宏文件 `.pptm`、加密或损坏的文件需要另行处理。
- 不直接输出 PDF。需要时用演示软件打开结果后导出。
- 备注只关联到同一源页的首张输出页。
- 会移除 `presentation.xml` 的扩展列表，以避免分节编号失配；分节及该扩展列表中的其他数据不保留。
- 内部跳转链接、自定义放映、动态页码、SmartArt 和图表细节尚未完整验收，不应承诺与原课件完全一致。
- 字体、公式兼容性和换行依赖实际演示软件与本机字体。保留 XML 坐标并不保证每种软件显示完全相同。
- 源媒体、嵌入对象、文档属性和部分备注会保留。透明文字仍可能被提取；工具不清除敏感内容。
- 会在内存中组织拆分后的 XML；复杂课件、很多点击步骤或大型媒体可能耗时并增加文件体积，未做性能上限验证。
- 最终保存依赖本地文件系统支持硬链接。若网络盘或移动盘不支持，请先输出到本机磁盘。

## 校验能证明什么

程序会检查输出文件结构、关系目标、内容类型、识别到的对象显隐、公式兼容分支、旧格式公式绘图、段落占位、移动缩放、图片、位置和异常重复页。

校验器与转换器共享部分动画解析和变换逻辑，因此二者可能存在共同盲区。退出码为 0 只能说明检查范围内没有发现错误。交付前仍需在实际演示软件中检查关键页面；本项目的具体已验证范围见 [VALIDATION.md](VALIDATION.md)。
