# 支持范围与已知限制

## 拆分方式

按 `presentation.xml` 中的放映顺序读取源页。每张源页先输出进入页面后自动动画结束的状态，再输出各次点击结束的状态。“与上一动画同时”“上一动画之后”及其延时合并到同一点击组；不会为等待时间或动画中间帧另建页面。完全自动播放的源页可能只输出一页。

同组对象显隐按照开始、结束时间重放；文字、图片、形状和分组均有测试。同一个对象退出后再进入、同组出现后又消失，可以得到与前一页相同的静态终态；这类点击仍予以保留。

检测到未支持结构时默认停止，不生成输出。`--allow-partial` 仅用于生成须人工逐页核对的草稿，返回退出码 3；即使结构校验通过，也不表示这些效果已还原。解析器仍可能存在未识别出的不支持情况。

## 具体支持条件

| 类型 | 当前处理方式或条件 |
| --- | --- |
| 进入、退出 | 重放整对象或段落的最终显隐；不保留飞入、旋转、缩放等进入/退出过程中的中间姿态 |
| 段落 | 用透明占位保留文字、字体、换行与位置，不删除段落 |
| 公式 | 同步处理 Choice/Fallback 兼容分支，保留原生结构及所需命名空间；按显隐筛选旧式 OLE/VML 预览 |
| 自动与延时 | 识别主序列、点击/同时/之后组合、数字延时，以及可求值的 `onBegin` / `onEnd` 时间节点依赖 |
| 文字变色 | `style.color` 且有明确目标颜色的部分效果，可限定段落 |
| 旋转 | 整对象有明确 `by` 角度的旋转终态 |
| 图片、形状缩放 | 正数 `by` 比例，以中心为基准；图片保留裁剪 |
| 文字、分组缩放 | 含文字时仅支持等比缩放，且字号可由本地运行属性、段落默认属性或本地列表样式确定；调整字号和间距 |
| 路径移动 | 顶层对象、`origin=layout`、路径坐标轴未旋转；明确数值的 `M/L/C/Z/E` 指令及小写相对形式；支持多段线、三次贝塞尔曲线、封闭路径和连续路径终点 |
| 瞬时强调 | 已识别为 `fill=remove` 或自动反向、结束时复原的部分强调效果保留原状态 |
| 内部导航 | 内部页间链接指向目标源页的首个输出状态；自定义放映按原页序展开，保留重复源页 |
| 页面切换 | 删除切换效果和自动翻页设置，便于手动阅读静态状态 |

路径只求终点；封闭路径回到起点时，前后静态页面可以相同。连续路径使用源对象的布局中心作基准，不把后一路径误当作相对上一步的位移。

以下情况尚未支持，或检测到后会停止：对象点击触发的交互序列、重复播放、条件提前结束、嵌套顺序序列、不确定持续时间、循环时间依赖、自定义时间速度/筛选、主序列之外的效果、未知行为、按字符或对象内部元素动画、段落单独移动/缩放/旋转、非等比文字缩放、依赖主题或母版字号的文字缩放、原生数学公式缩放、分组内部路径、公式化路径，以及同一属性在同一对象上重叠播放。进入/退出后反向复原的效果也未支持。

视频或音频播放过程不能转成静态动画步骤。媒体文件可能仍保留在输出包中；移除幻灯片动画不会冻结 GIF、视频等媒体。

## 实际显示限制

WPS 原生复杂动画样例已经实际播放对照，包括螺旋、玩具风车、曲线进入/退出、缩放和复杂路径；具体数量与组合见 [VALIDATION.md](VALIDATION.md)。这不是 WPS 全部预设效果的逐项认证，也未验证 Microsoft PowerPoint、Windows WPS 或其他 WPS 版本。

同机 WPS 的播放态与静态态仍有少量边缘、字体栅格化差异。文字放大后会按新字号重新排版，和动画直接缩放文字画面的结果可能存在轻微字距/位置差异；本次原生样例在 2940 像素宽截图中观察到约 7 像素的文字左边缘差异。形状边缘也有细微差别。要求像素一致时，当前不能承诺满足。

## 文件限制

- 仅接收 `.pptx`；旧版 `.ppt`、宏文件 `.pptm`、加密或损坏文件需要另行处理。
- 不直接输出 PDF，需要用演示软件打开结果后导出。
- 备注只关联到同一源页的首张输出页。
- 会移除 `presentation.xml` 的扩展列表，以避免分节编号失配；分节及该扩展列表中的其他数据不保留。
- 内部导航已有自动检查，但复杂放映动作、动态页码、SmartArt 和图表内部元素尚未完整验收。
- 字体、公式兼容性和换行依赖实际软件与本机字体，保留 XML 不保证每种软件显示相同。
- 源媒体、嵌入对象、文档属性和部分备注会保留，透明文字仍可能被提取；工具不清除敏感内容。
- 在内存中组织输出 XML；很多点击或大型媒体可能耗时并增加体积，未做性能上限验证。
- 最终保存依赖文件系统支持硬链接；若网络盘或移动盘不支持，请先输出到本机磁盘。

## 校验能证明什么

程序检查结构、关系目标、内容类型、识别到的对象显隐、公式兼容分支、旧格式公式绘图、段落占位、移动缩放、图片、位置、内部导航和异常重复页。

校验器与转换器共享部分解析和变换逻辑，可能存在共同盲区。退出码 0 仅说明检查范围内没有发现错误。交付前仍需在实际演示软件中核对关键页面。
