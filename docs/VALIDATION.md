### 检查中修正的演示文件问题

首次演示文件虽然能被脚本解析并拆分，但 WPS 没有识别其动画，进入放映就显示全部文字。仅改 XML 命名空间前缀不能解决；补齐时间层级、开始条件与构建列表后，WPS 能正确播放两次点击。已将修正文件写回 `examples/demo.pptx`，重新运行 33 项测试并重新拆分，完成上述源文件与静态结果对照。旧文件只留在项目外的本地检查目录。

### 验证边界

本次实际显示结论只覆盖上述真实课件的 14 个状态与演示课件的 3 个状态，没有逐页验收全部 86 页，没有在 Microsoft PowerPoint、Windows 或其他字体环境验证，也未用本次检查覆盖移动、缩放等全部支持条件。媒体不冻结为静态图；源课件的 GIF 图片仍可能播放，不将其逐帧内容作为静态动画还原结果。
