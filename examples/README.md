# 演示课件

**简体中文** | [English](README.en.md)

`demo.pptx` 是新生成的 1 页通用演示文件，不来自老师课件。创建基础课件时使用了 python-pptx，再加入用于测试的 Open XML 动画；运行本项目不依赖 python-pptx。

示例的动画时间层级、开始条件和构建列表已补齐，并在 macOS WPS Office 12.1.29182 中实际播放核对。原示例仅通过自动拆分检查，WPS 未识别其动画；当前文件已替换为修正版本。

课件有 2 次点击：

1. 初始状态：题目 “What is 6 x 7?” 和提示可见，答案不可见。
2. 第一次点击后：“Answer: 42” 出现。
3. 第二次点击后：提示退出，题目和答案保留。

在项目根目录运行：

```sh
python3 -m pptx_animation_split split examples/demo.pptx demo-split.pptx
```

输出应为 3 页。结果必须使用新文件名；不要覆盖示例源文件。

## WPS 原生复杂动画样例

`animation-cases.pptx` 的动画由 macOS WPS Office 12.1.29182 的动画界面实际添加和保存，再整理成 5 页测试文件。文字、绿色形状和红蓝图片均为专门制作的通用素材，不含教学资料；文档作者属性已改为通用测试名称，并移除 WPS 的不透明跟踪属性。

| 源页 | 实际效果与组合 | 输出状态数 |
| --- | --- | --- |
| 1 | 文字螺旋飞入；形状玩具风车同时进入、延时 0.5 秒；图片曲线向上进入，在上一效果之后延时 0.75 秒 | 2 |
| 2 | 形状、文字、图片分别放大至 150%；文字同时开始、延时 0.3 秒；图片在上一效果之后延时 0.4 秒 | 2 |
| 3 | 文字螺旋飞出、形状玩具风车退出、图片向下曲线退出，各一次点击 | 4 |
| 4 | 图片泪滴形封闭路径、形状八角星封闭路径、文字自定义三次贝塞尔曲线，各一次点击 | 4 |
| 5 | 与第 1 页相同的三个进入效果，首个效果改为进入页面自动开始，保留同时/之后和延时组合 | 1 |

```sh
python3 -m pptx_animation_split split examples/animation-cases.pptx animation-cases-split.pptx
```

应得到 13 页。第 4 页的前两条路径回到起点，保留对应点击产生的相同终态页。第 5 页无需点击，自动效果完成后为一个静态状态。

已在上述 WPS 环境逐步播放源文件，并与全部 13 页输出实际对照。显隐、路径终点、图片裁剪符合预期；文字缩放及形状边缘存在少量像素差异，详见[验证记录](../docs/VALIDATION.md)。不是所有 WPS 效果的完整目录。

## 对象触发与重复样例

`interaction-repeat-cases.pptx` 共 3 页，默认拆成 8 页：

| 源页 | 内容与来源 | 输出状态数 |
| --- | --- | --- |
| 1 | WPS 界面设置形状放大重复 3 次，保留文字和图片的同时/之后组合 | 2 |
| 2 | WPS 界面设置形状循环到下一次点击；文字同时放大，图片在下一次普通点击放大 | 3 |
| 3 | 用标准 Open XML 时间树构造：普通点击放大形状与图片，点击星形触发文字放大 | 3 |

```sh
python3 -m pptx_animation_split split examples/interaction-repeat-cases.pptx interaction-repeat-split.pptx
```

第 2 页循环阶段的输出是代表状态，不是对任意停止时机的预测。第 3 页的源对象触发未在本机 Mac WPS 中成功播放，不能将其列为原软件实际放映验收通过；这页用于可复现的语义、结构和静态结果检查。前两页的效果在 WPS 界面设置并实际播放过。

`click-order.json` 示范把源第 3 页改为“先点击星形，再普通点击”，其他源页沿用默认顺序。拆分和校验均需传入 `--click-order examples/click-order.json`。不要覆盖样例源文件。
